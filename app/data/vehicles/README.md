# 차량 시연 데이터

현재 파일은 `avante-demo-v2.json`이며 차량 ID는 기존 `avante_demo`를 유지합니다.

- 트렁크 97 × 82 × 42 cm와 입구 99 × 41.5 cm는 초기 논의의 대표값입니다.
- 일반 좌석·폴딩 공간의 치수, 위치와 폴딩 구간은 다중 공간 계산을 확인하기 위한 합성값입니다. 실측한 아반떼의 형상·폴딩 기능을 의미하지 않습니다.
- 조수석 폴딩도 시연 가정입니다. 실제 지원 차량과 폴딩 구간을 확인한 뒤 교체해야 합니다.
- 모든 좌표는 트렁크 뒤쪽 왼쪽 바닥을 원점으로 하고, x는 오른쪽, y는 차량 앞쪽, z는 위쪽입니다.
- 한 물건은 하나의 공간에 들어가야 합니다. 여러 물건은 여러 공간에 나누어 놓을 수 있습니다.
- 실측값으로 교체할 때 공간·좌석 연결을 함께 갱신하고 `data_version`을 변경합니다.
